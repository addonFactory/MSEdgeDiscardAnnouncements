# MSEdgeDiscardAnnouncements（Microsoft Edge 通知屏蔽） #

* 作者：Beka Gozalishvili
* 下载[稳定版][1]

本插件用于屏蔽 Microsoft Edge 浏览器产生的部分烦人通知。所有通知均可在 NVDA 设置的对应插件类别中进行配置。

## 配置通知 ##

在通知列表中选择一项通知，然后在“操作”组合框中选择 NVDA 应如何处理它：

* 关闭：屏蔽该通知，与旧版本插件的行为相同；
* 朗读：朗读该通知。勾选“朗读自定义消息”并输入您自己的文字，即可替换 Microsoft Edge 的原始消息；
* 提示音：用一段提示音序列替代该通知。“配置提示音”会打开一个对话框，您可以在其中编排序列，每个提示音都可设置频率、长度、左右声道音量以及其后的停顿时间。
* 音频文件：用音频文件替代该通知；

少数条目（例如在地址栏输入时显示建议）是简单的开关设置。对于这些条目，由“启用”复选框代替“操作”组合框。

在旧版本插件中配置过的通知会保留原有设置：原先未勾选的将变为关闭，原先勾选的将变为朗读。

## 0.11 版的变更 ##
* 现在每项通知都可被关闭、朗读、替换为提示音序列，或替换为所选的音频文件并以配置的音量播放；
* 被朗读的通知可以用自定义消息替代 Microsoft Edge 的原始消息；
* 提示音序列逐个提示音编排，每个都可设置频率、长度、左右声道音量以及其后的停顿时间；
* 旧版本写入的设置会自动迁移：原先未勾选的变为关闭，原先勾选的变为朗读；
* 新增了进入与退出全屏、在全屏下显示与隐藏工具栏以及单个下载进度的通知 ID；
* 现在要求 NVDA 2024.1 或更高版本。

## 0.10 版的变更 ##
* 以更优雅的方式屏蔽后台下载通知；
* 修复了在 Edge 编辑框中删除字符时的报错；
* 新增了若干通知 ID；
* 兼容 NVDA 2024.1。

## 0.9 版的变更 ##
